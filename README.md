# 銀行洗錢防制（AML）異常交易預警系統建置歷程與技術決策 (POC)

> **2026-04 完成模型開發並已上線交易監控系統使用**  
> 本文透過工程筆記整理開發思考歷程與指標選型，內容已進行去識別化與脫敏處理，不包含任何內部營運機密與未公開資訊。

---

## 1. 專案背景與業務痛點

歷時約 1 年的專案推進中，核心挑戰並非純演算法調校，而是**「極端不平衡數據」與「審查人力被低風險誤報淹沒」的生產瓶頸**：

* **傳統規則誤報率極高，排查量能癱瘓：**  
  傳統監控規則依賴靜態門檻，導致每日產生大量「合法但觸發規則」的無效警報。審查人員必須花費 70% 以上的工時逐筆調閱傳票進行排除，深陷警報疲勞（Alert Fatigue）。
* **極端稀疏標籤與評估失真：**  
  合法交易佔 99.9% 以上，真正經完整調查確認為高風險或申報可疑交易（STR）的樣本比例極低（陽性率 < 0.05%），傳統 Accuracy 或 ROC-AUC 指標在此類極端不平衡情境下完全失真。
* **分流結案與法遵可解釋性門檻：**  
  模型目標不只是「抓出壞人」，更需提供高信賴度的**低風險評分機制**協助審核員快速結案；同時必須輸出明確的特徵歸因依據，通過法遵與內部稽核檢驗。

## 2. 端到端實作階段與思考歷程

### Phase 1：需求訪談與分流策略收斂 (Triage Strategy)
* 與法遵及一線審查團隊梳理作業流程，確認最佳解方為**「風險分層分流機制（Tiered Risk Triage）」**：
  1. **高風險端：** 鎖定最可疑交易（Top-0.5%），提供明確特徵依據以加速立案。
  2. **低風險端：** 對海量誤報案件給予穩定低分並標註安全特徵，賦予審核員快速結案（Fast-Track Clearance）的信心。
* **指標定錨：** 放棄全域 ROC-AUC，改以 **PR-AUC**、**Top-K 捕獲率（Capture Rate）** 以及 **低風險分流準確率** 作為驗證核心。

### Phase 2：特徵工程與冷熱特徵切分
* 透過 SQL 與 Polars 建立多維度時序聚合指標（1d, 7d, 30d 交易頻率、資金滯留時間、流動對手集中度比率等）。
* **踩坑與取捨：**  
  初期衍生了 100+ 個特徵，但在跨期驗證（OOT）時發現部分依賴「特定跨月統計」的特徵衰退極快（Data Drift）。後續利用 SHAP 值與族群穩定度指標（PSI）進行剪枝，將特徵精煉至穩定度最高的 10 餘個核心行為特徵，確保跨季度運作不失效。

### Phase 3：模型建置與極端不平衡策略演進
在極端少樣本下，嘗試了不同的處理手段，演進歷程如下：

1. **嘗試 SMOTE / 過抽樣（大失敗）：**
   * *實作嘗試：* 使用 SMOTE 在少數類別周圍合成虛擬樣本以平衡類別比。
   * *實測結果：* 離線訓練集評分看似提升，但推到跨期測試集時，**False Alarm 暴增近 40%**。
   * *根本原因：* 在高維稀疏空間且陽性樣本極少的情況下，K-NN 插值容易在多數類別的「雜訊邊界」生成錯誤的異常樣本，徹底破壞決策邊界。**最終果斷棄用 SMOTE。**
2. **改採代價敏感學習：**
   * *實作嘗試：* 評估直接設定 `scale_pos_weight = 負樣本數 / 正樣本數`（約 2000~3000）。
   * *實測結果：* 梯度震盪劇烈，模型對邊界極端值過度敏感，收斂困難。
3. **最終解方：平方根阻尼加權（Damped Scale-Pos-Weight） + 雙向閾值截斷：**
   * 取平方根進行加權阻尼（`np.sqrt(neg_count / pos_count)`），將權重控制在 ~50 左右，搭配 LightGBM 樹深限制（max_depth=3~4），抑制過擬合並確保機率校準（Calibration）平滑，使高分與低分端皆具備可信度。

### Phase 4：模型驗證與可解釋性導入 (Explainability)
* 採用嚴格的 **Out-of-Time (OOT) 跨期驗證**，模擬上線後跨季運作的情境，杜絕時間序列上的數據穿越（Data Leakage）。
* 導入 **SHAP (TreeExplainer)**：
  * **高風險案件：** 輸出異常特徵貢獻圖，作為排查工單的「推薦重點」。
  * **低風險案件：** 驗證其核心行為特徵均落於正常基準線內，提供審核員快速結案的佐證依據。

## 3. 上線成效與業務價值 (Production Impact)

模型於 2026-04 正式上線交易監控系統，達成以下具體效益：

* **審案效率提升約 70%：**  
  透過低風險案件的智慧評分與分流，審核員無須再逐筆翻閱完整傳票，大量降低無效誤報的調查耗時，整體審案平均處理時間大幅縮減 70%。
* **AML 審查精度提升約 9 成：**  
  有效過濾系統性雜訊，高風險警報池中的案件純度大幅拉高，第一線調查人員得以全神貫注於真正具備洗錢威脅的複雜案件，顯著提升最終可疑交易（STR）的申報質量。

---

## 4. 核心工程總結

* **模型價值在於「雙向分流」：** 在合規調查中，精準識別「安全案件」以釋放人力，與抓出「異常案件」同等重要。
* **放棄教科書迷思：** SMOTE 等合成過抽樣技術在極端稀疏的真實業務數據中往往弊大於利，損失加權阻尼搭配特徵剪枝更為穩健。
* **可解釋性是落地的敲門磚：** 工程師若無法向業務端解釋「為什麼能判定為低風險而快結」，再高的理論分數也無法通過內部法遵與稽核。
